# Programa de Investigación: Cognición, Semiótica y Psicología Cuántico-like

## 1. Propósito

Este repositorio forma parte de un programa experimental que estudia si formalismos de probabilidad cuántica pueden servir como modelos computacionales de estados semánticos, cognitivos y psicológicos.

El término **cuántico-like** es deliberado: no se afirma que el cerebro sea un sistema cuántico físico ni que los arquetipos o la sincronicidad sean fenómenos de entrelazamiento físico.

La pregunta central es:

> ¿Pueden los estados semánticos y psicológicos modelarse como estados contextuales cuya evolución depende de símbolos, contexto, memoria y observación, y en determinadas tareas un modelo cuántico-like explica los datos mejor que un modelo clásico?

## 2. Arquitectura conceptual

- **Saussure-Quantum**: motor semiótico. Modela signo, significado, contexto y composición semántica.
- **Laboratorio Cuántico-Junguiano**: motor psicológico. Modela estados simbólicos, transformación y observación.
- **Psyche-Simulacra**: candidato a capa de simulación de agentes/psique.
- **Cerebro Artificial**: candidato a integración cognitiva superior.

La arquitectura objetivo es:

    símbolo/significado
          ↓
    estado semántico
          ↓ contexto
    estado psicológico
          ↓ observación
    decisión / transformación
          ↓
    trayectoria temporal

## 3. Principios epistemológicos

1. Toda analogía debe convertirse en una hipótesis operacional.
2. Cada fenómeno debe tener un modelo clásico de control.
3. Un modelo cuántico-like sólo gana valor si explica mejor los datos o produce predicciones nuevas.
4. Las categorías junguianas se tratarán inicialmente como hipótesis/modelos interpretativos, no como entidades científicas demostradas.
5. La sincronicidad se modelará primero como experiencia de coincidencia significativa, no como entrelazamiento físico.
6. Los resultados negativos son resultados válidos.
7. Toda afirmación experimental debe registrar datos, variables, procedimiento, predicción y limitaciones.

## 5. Modelos a comparar

Para cada experimento se implementarán, cuando sea posible:

1. Modelo clásico.
2. Modelo vectorial/probabilístico.
3. Modelo cuántico-like.
4. Modelo cuántico-like enriquecido con categorías junguianas.

Esto evita asumir de antemano que la interpretación junguiana mejora el modelo.

## 6. Métricas

Según el experimento:

- log-likelihood
- BIC/AIC
- RMSE/MAE
- R²
- calibración probabilística
- entropía de Shannon
- fidelidad
- pureza
- coherencia
- distancia de estados
- error de reconstrucción tomográfica
- efectos de orden
- tamaño de efecto y, cuando corresponda, intervalos de confianza

## 7. Ruta de maduración

Fase A: formalización matemática.
Fase B: reproducibilidad computacional.
Fase C: experimentos sintéticos.
Fase D: datos humanos/corpus.
Fase E: comparación estadística de modelos.
Fase F: integración semántica + psicológica.
Fase G: simulación de agentes.

## 8. Criterio de éxito

El proyecto no busca demostrar que Jung o la mecánica cuántica describen literalmente la mente.

Busca determinar si una representación contextual no clásica proporciona ventajas explicativas, predictivas o computacionales sobre alternativas clásicas en dominios definidos.

## 9. Limitaciones

- No es una herramienta clínica validada.
- Las salidas Bayesianas actuales no constituyen diagnóstico psicológico.
- La analogía entre decoherencia y represión es un recurso de modelado, no una equivalencia neurobiológica.
- La analogía entre entrelazamiento y sincronicidad no implica causalidad física.
- Los resultados computacionales no validan por sí solos afirmaciones ontológicas sobre la psique.
