# E003 — Correlación Bell y medidas de entrelazamiento

## Objetivo

Separar tres conceptos que antes estaban mezclados:

1. correlación observable;
2. entrelazamiento del estado;
3. interpretación simbólica de una correlación.

## Estado inicial

Se utiliza |Φ+⟩ = (|00⟩ + |11⟩)/√2.

## Métricas

- P(X₁=X₂);
- negatividad;
- concurrencia;
- entropía reducida;
- pureza global.

## Experimento

Barrido de γ desde 0 hasta 1. Para cada punto:

1. crear un estado Bell nuevo;
2. aplicar el canal;
3. calcular las métricas directamente desde ρ;
4. repetir mediciones Monte Carlo;
5. comparar estimación y valor analítico.

## Resultado esperado

El experimento debe permitir distinguir una correlación residual de un estado realmente entrelazado.

## Interpretación

No se utilizará E003 para afirmar que existe "sincronicidad cuántica" en personas. El resultado sólo establece propiedades del modelo matemático.
