# E001 — Fundamentos del estado cuántico-like

## Estado

Implementación inicial.

## Pregunta

¿La infraestructura matemática reproduce de forma estable las propiedades básicas que luego utilizaremos como lenguaje de modelado?

## Hipótesis

H1. Los estados se normalizan correctamente.
H2. Las mediciones convergen a las probabilidades teóricas.
H3. Las transformaciones unitarias preservan la norma.
H4. El estado Bell inicial presenta entrelazamiento medible.
H5. El desfase completo elimina ese entrelazamiento para el canal definido.
H6. La tomografía reconstruye aproximadamente el estado a partir de mediciones.

## Baseline

Para E001 el baseline no es psicológico: son las ecuaciones analíticas de un qubit y un par Bell.

## Métricas

- error absoluto de probabilidades;
- fidelidad de estado;
- pureza;
- negatividad;
- concurrencia;
- correlación en base X.

## Criterio de aceptación

Los tests automatizados deben comprobar invariantes matemáticos y tolerancias estadísticas explícitas.

## Nota epistemológica

E001 valida la infraestructura matemática. No valida ninguna interpretación junguiana.
